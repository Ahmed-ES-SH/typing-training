## Brand & Style

The design system embodies a modern, high-precision engineering workspace designed for technical practitioners, cloud architects, and systems developers. It moves past cold monochrome consoles and dated CRT-green terminals, establishing an environment that combines the tactical clarity of mission-control telemetry with the tactile elegance of premium hardware interfaces.

### Brand Personality
- **Precise & Uncompromising:** Dense, low-latency, and strictly aligned. Every line and stroke serves structural readability.
- **Radiant & Incandescent:** Kinetic energy focused through blazing amber-orange heat lines, glowing indices, and active state conduits amidst dark obsidian space.
- **Architectural & Tactile:** Multi-layered obsidian surfaces grounded by hairline dividers, soft bevel accents, and subdued directional ambient backlights.

### Design Movement & Aesthetic
- **Polished Dark Tactical:** Obsidian and deep charcoal containers set against hairline borders (`#24334a`).
- **Glow-Conduit Telemetry:** Micro-highlights, luminescent neon amber halos for dynamic metrics, real-time indicators, and focus rings.
- **Engineered Micro-Affordances:** Meticulously calibrated interactive tokens designed for deep work, fast keyboard navigation, and long sessions without visual fatigue.

## Colors

The chromatic architecture is constructed on an obsidian bedrock, contrasted against molten orange telemetry and cold slate functional steps.

### Core Surfaces
- **Obsidian Root (Canvas):** `#090d16` — The foundational backdrop for app shells, root viewports, and primary gutter regions.
- **Deep Slate (Surface Container):** `#0e1626` — Standard panels, toolbars, sidebar docks, and code review containers.
- **Obsidian Lift (Surface Container High):** `#151f32` — Elevated cards, modal dialogs, flyout command bars, and active tabs.
- **Obsidian Highlight (Surface Container Highest):** `#1c2b44` — Hover states, selected rows, active split panes, and header rails.

### Structural Lines
- **Hairline Border Subdued:** `#1b283d` — Structural grids, subtle row separators, and inactive tab dividers.
- **Hairline Border Base:** `#24334a` — Standard structural bounding frames, input field borders, card perimeters.
- **Hairline Border Focus / Active:** `#f97316` — Dynamic keyboard focus traps, selected cards, active terminal splits.

### Telemetry Accents & Radiant Heat
- **Incandescent Core (Primary):** `#f97316` — Primary interactive triggers, active breadcrumbs, syntax keywords, focus borders.
- **Neon Amber Light (Secondary):** `#fb923c` — Telemetry highlights, hover glow reflections, active status tags, diff additions.
- **Molten Orange Deep (Tertiary):** `#ea580c` — Pressed button states, critical warnings, build metrics, secondary accents.
- **Amber Glow Wash:** `rgba(249, 115, 22, 0.12)` — Ambient backplates, active badge fills, terminal selections.

### Text & Telemetry Contrast
- **Text High-Contrast (Foreground):** `#f8fafc` — Primary headers, variable names, active metric counters.
- **Text Subdued (Muted):** `#94a3b8` — Code comments, secondary parameters, timestamps, metadata keys.
- **Text De-emphasized:** `#64748b` — Inactive breadcrumbs, table header labels, line numbers.

## Typography

The typography couples the universal clarity of **Inter** for structural prose and UI scaffolding with the monospaced mechanical precision of **JetBrains Mono** for developer workflows, telemetry dashboards, parameters, and live console outputs.

### Typographic Hierarchy Rules
- All high-level layout containers, navigation anchors, modal titles, and descriptive passages employ **Inter**.
- Any string containing machine outputs, numeric counts, micro-status pill tags, environment identifiers, key-value pairs, or raw configuration paths defaults to **JetBrains Mono**.
- Optical kerning is enabled; headings utilize negative tracking to compress visual density for immediate scan speed across technical layouts.
- `label-sm` utilizes an uppercase transformation paired with `0.06em` tracking for hardware-inspired status tags and panel metadata headers.

## Layout & Spacing

This design system uses a strict **8pt / 4pt baseline grid** optimized for high information density without clutter.

### Layout Philosophy
- **Modular Fluid Grid with Fixed Chrome:** Main navigation trees and configuration sidebars operate at fixed widths (`sidebar-width: 16rem`), while telemetry charts, code diff views, and run consoles flex dynamically to occupy remaining viewport real estate.
- **Split-Pane Architecture:** Heavy reliance on resilient split panes with thin 1px boundary hit-areas for resizing workspace segments.

### Responsive Breakpoints & Adapters
- **Desktop (>1280px):** Multi-column viewport with persistent left-hand navigation, middle workspace canvas (grid or code terminal), and an optional collapsible telemetry inspector on the right. Margin standard: `1.25rem`.
- **Tablet (768px – 1279px):** Inspector collapses to a slide-over panel. Sidebar compresses into an icon-only quick rail (`4rem` width).
- **Mobile (<767px):** Single-column stack. Sidebar shifts to a sliding bottom-sheet or full-screen overlay. Primary code containers gain horizontal auto-scrolling with sticky line numbering.

## Elevation & Depth

Visual hierarchy is maintained through disciplined tonal stepping combined with low-contrast structural outlines and diffuse neon amber backlights. Drop shadows remain near-black with tight radii, preventing muddy overlap.

### Tonal Hierarchy
1. **Base Layer (Elevation 0 - Shell Canvas):** `#090d16`. Ground-level container for desktop viewport borders, gutter lines, and underlying canvases.
2. **First Tier (Elevation 1 - Panels & Nav):** `#0e1626` bounded by a 1px border of `#24334a`. Used for split sidebars, status bars, and document bodies.
3. **Second Tier (Elevation 2 - Cards & Workspaces):** `#151f32` with a 1px border of `#24334a`. Shadow: `0 4px 16px -2px rgba(0, 0, 0, 0.6)`.
4. **Floating Tier (Elevation 3 - Flyouts, Dropdowns, Command Palettes):** `#1c2b44` bounded by `#2f4463`. Shadow: `0 12px 32px -4px rgba(0, 0, 0, 0.8), 0 0 0 1px rgba(249, 115, 22, 0.15)`.

### Telemetry Glow Accents
- Active execution flows, selected IDE tabs, and targeted console widgets feature an internal ambient glow: `box-shadow: inset 0 0 12px rgba(249, 115, 22, 0.08), 0 0 20px rgba(249, 115, 22, 0.15)`.
- Critical system alerts and pipeline breaks swap amber radiance for high-energy crimson-orange pulse rings.

## Shapes

The system uses a calibrated soft-tech aesthetic. It avoids both harsh 90-degree corners and circular pill geometry, settling on a clean, industrial contour profile.

### Corner Radii Guidelines
- **Base Components (`rounded` / 0.25rem - 4px):** Checkboxes, code tag pills, inline parameters, breadcrumb markers.
- **Interactive Containers (`rounded-lg` / 0.5rem - 8px):** Primary buttons, input fields, dropdown trigger buttons, tab elements, table wrappers.
- **Large Panels & Dialogs (`rounded-xl` / 0.75rem - 12px):** Command palettes, configuration modals, terminal drawers, detached cards.
- **Circle (`rounded-full`):** Reserved exclusively for live pipeline ping indicators, connection status dots, and author avatars.

## Components

### Buttons
- **Primary:** Background `#f97316`, text `#090d16` (extra-bold readability), subtle inner highlight border `1px solid rgba(255, 255, 255, 0.25)`. Hover: `#fb923c` with `box-shadow: 0 0 16px rgba(249, 115, 22, 0.35)`. Active: `#ea580c`. Height: 36px (compact desktop) or 44px (mobile).
- **Secondary / Ghost:** Surface `#151f32`, border `1px solid #24334a`, text `#f8fafc`. Hover: border `#f97316`, text `#fb923c`, surface `#1c2b44`.
- **Destructive:** Surface `rgba(234, 88, 12, 0.1)`, border `1px solid #ea580c`, text `#fb923c`. Hover: surface `#ea580c`, text `#090d16`.

### Inputs & Text Areas
- **Container:** Surface `#090d16`, border `1px solid #24334a`, radius `rounded-lg` (8px).
- **Text:** Font `Inter` or `JetBrains Mono` based on semantic context, color `#f8fafc`, placeholder `#64748b`.
- **Focus State:** Border color `#f97316`, box-shadow `0 0 0 1px #f97316, 0 0 12px rgba(249, 115, 22, 0.2)`. Transition: 150ms ease-out.

### Status Badges & Chips
- **Telemetry Indicators:** Font `JetBrains Mono` (`label-sm`), uppercase, border radius `4px`.
- **Operational / Healthy:** Background `rgba(249, 115, 22, 0.1)`, border `1px solid rgba(249, 115, 22, 0.3)`, text `#fb923c`. Paired with a 6px pulsating dot.
- **Neutral / Draft:** Background `#151f32`, border `1px solid #24334a`, text `#94a3b8`.

### Checkboxes & Radios
- **Unchecked:** 16x16px, surface `#090d16`, border `1px solid #24334a`, radius `4px`.
- **Checked:** Surface `#f97316`, border `#f97316`, tick mark `#090d16` (solid stroke). Focus ring: `0 0 0 2px rgba(249, 115, 22, 0.3)`.

### Code Blocks & Terminal Windows
- **Shell:** Background `#090d16`, header bar `#0e1626` with hairline border bottom `#24334a`.
- **Code Viewport:** Font `JetBrains Mono`, regular weight, line height 1.6, line numbers in `#64748b`. Highlighted line background: `rgba(249, 115, 22, 0.08)` with left border indicator `2px solid #f97316`.

### Cards & Panels
- Surface `#0e1626`, perimeter border `1px solid #24334a`, corner radius `8px`. Padding standard: `space-base` (16px).
- **Interactive Card Hover:** Top edge gains a glowing gradient hairline: `background: linear-gradient(90deg, transparent, #f97316, transparent)`.
