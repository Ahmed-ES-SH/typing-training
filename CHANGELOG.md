# Changelog

All notable changes to **TypeKernel** — an offline-first desktop trainer for
coding touch-typing. Local SQLite persistence only; no backend, no accounts,
no cloud.

## [1.0.0] — 2026-09-06

Phases 1–8 built the product; Phase 9 (this release) ships it.

### Packaging & identity (Phase 9)
- Final **TypeKernel** identity: `com.typekernel.app`, product/window name
  `TypeKernel`, full generated icon set from the terminal-chevron glyph.
- First-boot adoption of pre-1.0 dev data: a DB living under the legacy
  `com.adev.typing-trainer` dir is copied into the new identifier's dir on
  first boot (legacy copy preserved).
- AppImage as the primary distributable; `packaging/arch/PKGBUILD` (-bin
  style) producing a native `.pkg.tar.zst` with `/usr/bin/typekernel`,
  hicolor icons and a proper desktop entry; from-source PKGBUILD scaffold.
- AUR submission scaffold (`packaging/aur/`) — unpublished by design.
- Offline audit (PRD §5): automated `unshare -rn` boot test + code audit —
  the only outbound-capable path is the manual "Check for Updates" browser
  hand-off. See `docs/release/offline-audit.md`.
- Release scaffolding: this changelog, real README, release checklist,
  platform-verification record.

### Application shell (Phase 2)
- Clean TypeKernel-styled app shell: boilerplate removed, design tokens in
  Tailwind 4, self-hosted fonts/icons (fully offline), zustand navigation
  across the 8 screens, all screens present as stubs.

### Data layer & typing engine (Phase 3)
- SQLite via `tauri-plugin-sql` bridged to Drizzle ORM with all 8 tables,
  idempotent migrations, Zod-validated domain types.
- Pure, unit-testable typing engine: real-time WPM/accuracy/error metrics,
  layout-agnostic QWERTY keymap, session store, attempts persisted to SQLite.

### Curriculum & core loop (Phase 4)
- Bundled 260-lesson progressive curriculum generated by curated scripts,
  programming-symbol focus.
- Unlock rule (accuracy ≥ 95 AND WPM > 45, same attempt, permanent) wired
  into the session flow; attempt numbering and per-lesson stats.
- Lessons directory + Lesson Results screens; the full PRD loop works
  end-to-end.

### Progress & statistics (Phase 5)
- Dashboard: overall progress, current lesson, recent attempts, streak,
  weak keys, quick access to weakness training.
- Statistics screen: WPM/accuracy history charts, per-lesson/per-attempt
  performance, curriculum progress, raw attempt log — raw history is never
  reduced to a best score.

### Intelligence (Phase 6)
- Key heatmap (strong/average/weak/frequently-incorrect) on Statistics and
  compact in-session.
- Weakness analyzer (wrong keys, bigrams, error patterns) feeding adaptive
  lesson content.
- Weakness Training mode generating evolving drills from the weakest
  keys/symbols.

### Custom lessons & settings (Phase 7)
- Custom lesson authoring (create/edit/delete/practice), local JSON
  import/export for lessons, collections and progress backups with strict
  validation, full Settings screen wired into the `settings` table.

### Daily training & polish (Phase 8)
- Daily goal editing, daily tracking, streaks and consistency view.
- Performance pass against the non-functional budget, UX polish sweep,
  release-candidate verification.
